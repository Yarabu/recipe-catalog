# Recipe Catalog

**Призначення проєкту:** вебзастосунок для швидкого пошуку рецептів.

**Предметна область:** каталог рецептів.

**Використані технології:**

- HTML5, CSS3
- TypeScript
- Vite, npm
- Fetch API

## API

Дані беруться з [DummyJSON Recipes API](https://dummyjson.com/docs/recipes).

| Ендпоінт                 | Призначення                  |
| ------------------------ | ---------------------------- |
| `GET /recipes`           | список рецептів з пагінацією |
| `GET /recipes/search?q=` | пошук за назвою              |
| `GET /recipes/tag/{tag}` | фільтр за тегом              |
| `GET /recipes/tags`      | список тегів                 |
| `GET /recipes/{id}`      | деталі рецепта               |

## Запуск

1. `git clone https://github.com/Yarabu/recipe-catalog`
2. `cd recipe-catalog`
3. `npm install`
4. `npm run dev`

Тести: `npm test`. Збірка: `npm run build`.

## Основна функціональність

- Головна сторінка з пошуком, популярними тегами та найкращими рецептами.
- Каталог: пошук, фільтр за тегом, сортування, пагінація.
- Сторінка рецепта: інгредієнти, інструкція, час, калорійність.
- Стани завантаження та помилки (з кнопкою повтору).

## Технічний звіт

- **Структура:** MPA з трьох сторінок (головна, каталог, деталі). Код розділений на модулі: `api`, `components`, `pages`, `types`, `utils`.
- **TypeScript:** типи для рецептів, відповідей API та параметрів запитів.
- **API:** усі запити в одному модулі.
- **Безпека:** дані з API екрануються функцією `escapeHtml` (захист від XSS).
- **Accessibility:** семантична розмітка, skip-link, видимий фокус, `aria-live` для станів, достатній контраст.
- **Responsive:** CSS Grid і Flexbox, адаптація під мобільні екрани.
- **Тести:** 7 unit-тестів (екранування та картка рецепта), а також ручне тестування та Lighthouse.
- **Обмеження:** пошук і тег не комбінуються (окремі ендпоінти API), стан каталогу не зберігається в URL.
